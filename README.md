# 📅 SimpleCalendar

**SimpleCalendar** — это легкое и удобное приложение-календарь для Android, разработанное на **.NET MAUI**. Оно позволяет создавать заметки и события, добавлять к ним стикеры и сохранять все данные локально на устройстве.

## Возможности

- **Управление событиями**: Создание, просмотр и удаление заметок и событий.
- **Выбор даты**: Интерактивный календарь для навигации по дням.
- **Стикеры**: Добавление эмодзи-стикеров (🎉, 🔥, 📌, ⭐) к событиям для быстрой визуальной идентификации.
- **Локальное хранение**: Все данные сохраняются в формате JSON в изолированном хранилище устройства (не требуют интернета).
- **Современный UI**: Построен на основе .NET MAUI с использованием XAML.

## Технологии

- **Платформа**: .NET MAUI (Android)
- **Язык**: C#
- **Хранение данных**: `System.Text.Json` + `FileSystem.AppDataDirectory`
- **UI**: XAML (CollectionView, Grid, Frame)
- **Целевая версия**: .NET 10.0 (Android)

## Пошаговая инструкция работы

1. Подготовка к добавлению
- Откройте приложение SimpleCalendar.
- На главном экране выберите дату в календаре (нажмите на нужное число).
- Ниже, под календарем, вы должны увидеть кнопки «Заметка» и «Событие».

2. Выбор стикера
- Перед тем как нажать кнопку добавления, посмотрите на экран:
- У вас должна быть панель со стикерами (обычно это ряд кнопок с эмодзи: 🎉, 🔥, 📌, ⭐).
- Нажмите на любой стикер из этой панели. Он должен визуально выделиться (например, изменится цвет фона кнопки или появится галочка), показывая, что он выбран.
⚠️ Важно: Если вы нажмете на стикер после того, как создали событие, он не применится к нему. Стикер нужно выбирать до нажатия кнопки «Добавить».

3. Создание события/заметки
- После выбора стикера нажмите кнопку «Событие» (или «Заметка»).
- В появившемся всплывающем окне введите название (например, «Встреча»).
- Введите время (например, «15:00»).
- Нажмите «ОК» или «Сохранить».
